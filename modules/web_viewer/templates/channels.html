Canaux

Les canaux connus de ce bot, avec le code d'ajout MeshCore de chacun. Scannez-le dans l'application MeshCore (Canaux, puis « + » → « Scanner un code QR »), ou copiez le lien vers un téléphone : un navigateur d'ordinateur n'ouvre pas les liens meshcore://.

Un badge dit ce que le bot fait de chaque canal : « surveillé » — il y répond ; « sur la radio » — le nœud y est abonné ; « décodé » — le bot en connaît la clé (liste de canaux de la commande channels et canaux de décodage de la configuration), mais le nœud n'y a pas de slot. Seuls les canaux dièse et les canaux personnalisés que l'opérateur a publiés sur le web ont un code visible ici. Le canal Public n'est pas distribué.
