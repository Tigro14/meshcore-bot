Channels

The channels this bot knows about, each with its MeshCore add code. Scan it in the MeshCore app (Channels, then “ + ” → “ Scan QR Code ”), or copy the link to a phone : a desktop browser does not open meshcore:// links.

A badge says what the bot does with each channel : “monitored” — it answers there; “on radio” — the node holds a slot for it; “decoded” — the bot knows its key (the channels command list and the configured decode channels) but the node has no slot for it. Only hashtag channels, and custom channels the operator published on the web, get a visible code here. The Public channel is not handed out.
