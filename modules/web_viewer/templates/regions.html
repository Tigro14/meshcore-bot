Avertissements de région

Pourquoi ce bot vous envoie parfois un message sur votre code de région — et quelle part du trafic du mesh cela concerne.

Pourquoi recevez-vous un avertissement ?

Chaque message en MeshCore porte un code de région — une petite étiquette indiquant à quelle partie du mesh il appartient. Les nœuds l'utilisent pour décider qui doit relayer un message et jusqu'où il doit voyager.

Quand un message est envoyé sans code de région, le mesh ne peut pas le limiter : il est traité comme global et est relayé à l'ensemble du mesh, pas seulement à votre région. Chaque tel message consomme de l'énergie et de la batterie sur des nœuds qui n'ont rien à voir avec lui.

Ce bot écoute le trafic des canaux, compte combien de messages n'ont pas de code de région, et — quand ce schéma est régulier de la part d'un même émetteur — envoie à cet émetteur une brève alerte. L'objectif est de garder le mesh calme, pas de surveiller qui que ce soit : définir un code de région ne prend qu'un instant dans l'application MeshCore et résout le problème à la source. Avec une interconnexion de plus en plus forte entre régions voire pays, cette contrainte s'impose à tous.

Comment ça marche
  1. Le bot ne fait qu'écouter. Il lit le trafic des canaux qui traverse le mesh et note, par jour et par canal, combien de messages avaient un code de région et combien n'en avaient pas. Il ne lit pas le contenu des messages.
  2. Il avertit, avec parcimonie. Un émetteur n'est contacté qu'après avoir envoyé plusieurs messages sans code de région, et seulement à une fréquence limitée : il y a un délai par émetteur, un intervalle minimal entre deux avertissements quelconques, et un plafond journalier sur le nombre total envoyé.
  3. Vous pouvez l'arrêter. Définissez un code de région dans votre application MeshCore et les avertissements cessent d'eux-mêmes — c'est la solution.

In English

For visitors who do not read French: this page explains why you may have received a warning message about your region code, and how much of the mesh traffic that is about.

Why do you get a warning?

Every message on the mesh carries a region code — a small label saying which part of the mesh it belongs to. Nodes use it to decide who should relay a message and how far it should travel.

When a message is sent without a region code, the mesh cannot limit it: it is treated as global and is relayed to the entire mesh, not just your region. This bot listens to channel traffic, tallies how many messages have no region code, and — when that pattern is consistent from a single sender — sends that sender a short heads-up. The goal is to keep the mesh quiet, not to police anyone: setting a region code takes a moment in the MeshCore app and removes the problem at the source.

How it works
  1. The bot only listens. It reads the channel traffic passing through the mesh and records, per day and per channel, how many messages had a region code and how many did not. It does not read the message bodies.
  2. It warns, sparingly. A sender is only contacted after repeatedly sending messages without a region code, and only so often: there is a per-sender cooldown, a minimum gap between any two warnings, and a daily cap on the total number sent.
  3. You can stop it. Set a region code in your MeshCore app and the warnings stop on their own — that is the fix, not a complaint to file.
If you got one

Open the MeshCore app, add a region code to your node, and you are done — your messages will stop flooding the whole mesh and the bot will stop sending you the warning. If you believe the message is a mistake, the same page an admin uses to configure this is under Region Settings in the admin area.
