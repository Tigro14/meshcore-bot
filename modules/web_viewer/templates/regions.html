Region warnings

Why this bot sometimes sends you a message about your region code — and how much of the mesh traffic that is about.

Why do you get a warning?

Every message on the mesh carries a region code — a small label saying which part of the mesh it belongs to. Nodes use it to decide who should relay a message and how far it should travel.

When a message is sent without a region code, the mesh cannot limit it: it is treated as global and is relayed to the entire mesh, not just your region. Every such message burns airtime and battery on nodes that have nothing to do with it.

This bot listens to channel traffic, tallies how many messages have no region code, and — when that pattern is consistent from a single sender — sends that sender a short heads-up. The goal is to keep the mesh quiet, not to police anyone: setting a region code takes a moment in the MeshCore app and removes the problem at the source.

How it works
  1. The bot only listens. It reads the channel traffic passing through the mesh and records, per day and per channel, how many messages had a region code and how many did not. It does not read the message bodies.
  2. It warns, sparingly. A sender is only contacted after repeatedly sending messages without a region code, and only so often: there is a per-sender cooldown, a minimum gap between any two warnings, and a daily cap on the total number sent.
  3. You can stop it. Set a region code in your MeshCore app and the warnings stop on their own — that is the fix, not a complaint to file.

If you got one

Open the MeshCore app, add a region code to your node, and you are done — your messages will stop flooding the whole mesh and the bot will stop sending you the warning. If you believe the message is a mistake, the same page an admin uses to configure this is under Region in the admin area.
